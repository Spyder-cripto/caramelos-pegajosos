======
RULES
======

( Mecánica de Sticky Candy Puzzle Saga, de Alan Hazelden: los caramelos que se tocan quedan pegados para siempre )
( y se mueven juntos; si uno solo choca, no se mueve ninguno. )
[ > Player no MovS ] -> [ > Player MovS ]
[ > Player | Candy ] -> [ > Player | > Candy ]
[ moving Candy | stationary Candy ] -> [ moving Candy | moving Candy ]
[ > Candy | Obstaculo ] [ > Player | > Candy ] -> [ Candy | Obstaculo ] [ > Player | Candy ]
[ > Player | stationary Candy ] [ moving Candy ] -> [ > Player | Candy ] [ Candy ]

( Caramelo en su zona: ribete dorado )
late [ CR TR ] -> [ RD TR ]
late [ RD no TR ] -> [ CR ]
late [ CG TG ] -> [ GD TG ]
late [ GD no TG ] -> [ CG ]
late [ CB TB ] -> [ BD TB ]
late [ BD no TB ] -> [ CB ]
late [ CV TV ] -> [ VD TV ]
late [ VD no TV ] -> [ CV ]

( Puentes de miel entre los caramelos pegados )
late [ Pega ] -> [ ]
late right [ Candy | Candy ] -> [ Candy PegaR | Candy PegaL ]
late down [ Candy | Candy ] -> [ Candy PegaD | Candy PegaU ]

( Contador de pasos, copiado de El Cubo de Hielo )
